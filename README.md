# EduQuest Light & Life

AR multi-factor biology **growth lab** for the ALU AR/VR summative.

**Author:** Cannelle Mwiza
**GitHub:** https://github.com/cinna03/EduQuest-Digital-Lab

## Loop
Hypothesis → Place → Water at table → Real bright light → Real dark → Result → Reflect

## Why AR
- Water only in **table view** (not facing a lamp)
- Growth needs **real BRIGHT** light
- Night needs **real DARK**
- No “Add light” cheat finishes the lab

## Run
1. Open in Unity 6
2. **EduQuest → Build Light Lab Scene**
3. Play → allow camera
