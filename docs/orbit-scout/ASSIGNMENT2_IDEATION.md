## 2. Summary note — scope, objectives, and next steps

### Problem / opportunity
Many learners meet the solar system only through flat images or memorization. Spatial understanding (order of planets, relative traits, “which planet matches this clue?”) is hard without a physical model. AR can put a **tabletop solar system** in a classroom or home and turn recall into **play + feedback**.

### Project objective
Design and prototype **Orbit Scout**: a mobile AR (and editor-testable) Unity experience where the player:

1. Places a solar system on a detected plane  
2. Completes **mission levels** (clues, scoring, streaks, timed challenges)  
3. Answers by **tapping planets** in 3D space  
4. Sees clear UI for menu → level select → play → results  

**Success for this trimester** means a playable vertical slice that demonstrates AR Foundation skills, solid game/UI structure, and an educational theme tied to my ALU mission—suitable as a **portfolio piece** and a foundation for a possible **capstone** (e.g. classroom pilot, more content, teacher mode).

### In scope (this prototype)

| Area | What is included |
|------|------------------|
| **Platform** | Unity · AR Foundation on device (`SampleScene`) · desktop editor test scene for fast iteration |
| **Core loop** | Mission start → (AR place) → questions / planet taps → score & unlock rules → end screen |
| **Content** | Multiple levels with different rules (basics, restore/greyscale, timed multi-select, gauntlet) |
| **Tech stack** | AR plane detection + raycast placement, 3D solar system view, HUD, progress/unlocks |
| **Documentation** | Concept (this note), GDD/performance notes, README / run instructions as the build matures |

### Out of scope (deliberate cuts for this trimester)

- Full curriculum / multi-subject EduQuest product  
- Photoreal NASA textures, voice narration, multiplayer  
- App Store release / school LMS integration  
- Full accessibility audit (partial UI polish only)

These may return in **capstone / portfolio expansion**.

### Target users (prototype)

- Primary: secondary / early tertiary learners exploring astronomy  
- Secondary: ALU peers and instructors reviewing AR specialization work  
- Future: teachers needing a short “station” activity (capstone direction)

### Learning outcomes for me (specialization)

- Apply AR interactions (planes, placement, world-space input)  
- Structure a small game (controllers, HUD, levels, progress)  
- Ship a coherent vertical slice with clear scope boundaries
